# Introduction
Welcome to airLaunch, a simple, minimalistic x86-64 launcher for adding, removing and starting your own apps. The current status of airLaunch is in Early development, so please note that there will be bugs to come across.
## System Requirements
System Requirements for airLaunch are extremely minimal as its a bloat-free-m minimalistic app.
 - Windows 7 64-bit+
 - Intel Celeron 1.0GHz+ 64-bit
 - 512MB RAM
 - 32MB VRAM
 - 50MB Free Disk Space

## Sidenotes
**You can attempt to use airLaunch on macOS or Linux via Wine,
However doing so can result in bugs. There is issue support for macOS
& Linux via Wine, but bugs mentioned in such will very likely
NOT be fixed.**

**When reporting a bug to issue support on GitHub, Please include your system specifications in this format:
Computer model (optional for PC, Required for Laptop), example: MacBook Air 7,1
CPU (Needed), example: AMD Ryzen 5 3600
RAM Size, Speed & Amount (Needed), example: 2 Equal sticks of 8GB DDR4-3200 by G.Skill.
GPU (Needed), example: Intel HD Graphics 6000, NVIDIA GeForce GTX 1080 Ti.
PSU (Needed for PC, Optional for Laptop), example: 1000W 80+ Gold by Corsair
OS (REQUIRED. Full stop), example: Windows 10 Pro x64 21H1, macOS 15.5.1 Intel Seqouia via OpenCore, Linux Debian 12.1 x64**
